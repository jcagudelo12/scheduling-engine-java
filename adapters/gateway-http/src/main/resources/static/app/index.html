Asistente de horarios

Cliente de demostración del motor de horarios. Es un medio de prueba: el aporte principal es el motor.

1. Acceso

Pega el token firmado por la institución, o trabaja sin token si el motor corre con SCHED_AUTH=none (solo desarrollo). El token se guarda solo en esta pestaña (sessionStorage) y se borra al cerrarla.

2. Asignaturas

Códigos separados por coma o espacio, tal como están en el catálogo (por ejemplo MAT101, FIS101).
